# Mockup

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

แบ่งเป็น 2 ฝั่ง สลับได้จากปุ่มมุมขวาบน

## ฝั่งลูกค้า

เลือกสินค้า หลายหน่วยขาย ปุ่มบวก-ลบ ยอดรวมลอยด้านล่าง
สลับดูได้ว่าเปิดจากหน้าเว็บหลัก กับเปิดจากลิงก์ของกลุ่ม ต่างกันยังไง

## ฝั่งเจ้าของร้าน (ต้องใส่รหัส)

รหัสสำหรับทดลอง **123456**

| เมนู | ดูอะไรได้ |
|---|---|
| ภาพรวม | ยอดขายวันนี้/เดือนนี้ ค้างชำระ ต้องทำวันนี้ ยอดขาย 7 วัน สินค้าขายดี (กรองรายกลุ่มได้) ยอดขายแยกช่องทาง |
| สินค้า | เพิ่ม แก้ ลบสินค้า |
| แก้ราคา | แก้ราคากลางทีเดียวใช้ทุกที่ หรือเลือกกลุ่มเพื่อตั้งราคาเฉพาะ |
| กลุ่มและลิงก์ | กลุ่มลูกค้าพร้อมลิงก์สั่งซื้อของแต่ละรอบ |
| ใบพิมพ์ | ฟอร์มกระดาษคาร์บอน 80 มม. 3 แบบ สั่งพิมพ์ได้จริง |

กดใช้งานได้จริงทุกปุ่ม แต่ยังไม่ได้ต่อฐานข้อมูล ข้อมูลจะหายเมื่อรีเฟรชหน้า
