# Mockup

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

มี 4 หน้าให้ดู สลับได้จากปุ่มมุมขวาบน

1. **หน้าลูกค้า** — เลือกสินค้า หลายหน่วยขาย ปุ่มบวก-ลบ ยอดรวมลอยด้านล่าง
   สลับดูได้ว่าเปิดจากหน้าเว็บหลัก กับเปิดจากลิงก์ของกลุ่ม ต่างกันยังไง
2. **หน้าแก้ราคา** — แก้ราคากลางทีเดียวใช้ทุกที่ หรือเลือกกลุ่มเพื่อตั้งราคาเฉพาะ
3. **กลุ่มและลิงก์** — กลุ่มลูกค้าพร้อมลิงก์สั่งซื้อของแต่ละรอบ
4. **ใบพิมพ์ 80 มม.** — ฟอร์มกระดาษคาร์บอน 3 แบบ กดปุ่มสั่งพิมพ์ได้จริง
   (ตั้งขนาดกระดาษเป็น 80 มม. ในหน้าต่างพิมพ์ของเบราว์เซอร์)

กดใช้งานได้จริงทุกปุ่ม แต่ยังไม่ได้ต่อฐานข้อมูล ข้อมูลจะหายเมื่อรีเฟรชหน้า
