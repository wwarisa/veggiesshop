# ระบบร้านขายผัก [ชื่อร้าน]

เว็บสั่งผักออนไลน์สำหรับร้านขายผักที่ส่งเองเป็นรอบตามหมู่บ้าน
ลูกค้าสั่งผ่านมือถือโดยไม่ต้องสมัครสมาชิก เก็บเงินปลายทาง
เจ้าของร้านแก้ราคาเองได้ทุกวันผ่านหน้าจัดการภาษาไทย

**ค่าใช้จ่าย 0 บาท/เดือน** — ใช้บริการฟรีทั้งหมด ไม่ต้องผูกบัตรเครดิต

---

## เริ่มลองใช้ใน 2 คำสั่ง

```bash
npm install
npm run dev
```

เปิด `http://localhost:3000` ได้เลย ไม่ต้องสมัครหรือตั้งค่าอะไรก่อน
ระบบจะเก็บข้อมูลเป็นไฟล์ในโฟลเดอร์ `.data/` ให้เอง

เข้าหน้าจัดการที่ `/admin` ครั้งแรกจะให้ตั้งรหัส 6 หลักของตัวเอง

## สิ่งที่ระบบทำได้

**ฝั่งลูกค้า** — เลือกสินค้าหลายหน่วยขาย · ตะกร้าคิดยอดสด · สั่งโดยไม่ต้องสมัครสมาชิก ·
จำลูกค้าประจำจากเบอร์โทร · ลิงก์สั่งซื้อรายรอบที่ล็อกวันส่งไว้แล้ว ·
ช่อง "อื่นๆ" ให้พิมพ์ขอของนอกรายการ · ติดตามสถานะด้วยเบอร์หรือเลขออเดอร์

**ฝั่งเจ้าของร้าน** (ล็อกด้วยรหัส 6 หลัก) — แดชบอร์ดภาพรวม · แก้ราคาทั้งหน้าจบในครั้งเดียว ·
ราคาแยกรายกลุ่ม · เพิ่มแก้ลบสินค้า · จัดการออเดอร์ 2 สถานะแยกกัน ·
ปรับยอดตามน้ำหนักจริง · รอบส่งพร้อมลิงก์ · ใบพิมพ์กระดาษคาร์บอน 80 มม. 3 แบบ ·
ตามคนค้างเงิน · ทะเบียนลูกค้า · รายงานยอดขาย · ตั้งค่าร้าน

## เทคโนโลยี

- **Next.js 16** (App Router) + **Tailwind CSS 4**
- **Cloud Firestore** แพลนฟรี — ต่อผ่าน `@google-cloud/firestore` โดยตรง
- **Netlify** แพลนฟรี (อนุญาตให้ใช้เชิงพาณิชย์)

### หลักความปลอดภัย

1. เบราว์เซอร์คุยกับฐานข้อมูลตรงๆ ไม่ได้เลย ทุกอย่างผ่านเซิร์ฟเวอร์
2. ยอดเงินคำนวณฝั่งเซิร์ฟเวอร์เสมอ หน้าเว็บส่งมาแค่รหัสสินค้ากับจำนวน
3. รหัสเจ้าของเก็บเป็น hash ตรวจที่เซิร์ฟเวอร์ ผิด 5 ครั้งล็อก 15 นาที
4. ไม่มีรหัสเริ่มต้นติดมากับระบบ เจ้าของตั้งเองตอนเปิดใช้ครั้งแรก
5. กดสั่งซ้ำได้ออเดอร์เดิม ไม่สร้างใบใหม่

## โครงสร้างโปรเจกต์

```
src/
├─ app/
│  ├─ page.tsx              หน้าร้านหลัก
│  ├─ r/[slug]/             ลิงก์สั่งซื้อของรอบ
│  ├─ order/[orderNo]/      หน้ายืนยันหลังสั่ง
│  ├─ track/                ติดตามสถานะ
│  └─ admin/                หน้าจัดการทั้งหมด (ต้องใส่รหัส)
├─ components/              ชิ้นส่วนหน้าจอที่ใช้ซ้ำ
├─ lib/
│  ├─ db/                   สลับที่เก็บข้อมูลอัตโนมัติ (ไฟล์ ↔ Firestore)
│  ├─ pricing.ts            กฎราคา 2 ชั้น + คิดเงินฝั่งเซิร์ฟเวอร์
│  ├─ orders.ts             ระบบออเดอร์ทั้งหมด
│  └─ auth.ts               ตรวจรหัสและจัดการการล็อก
└─ middleware.ts            กันคนนอกเข้า /admin
```
